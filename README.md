# Dynamic Business Reporting Dashboard | Microsoft Excel

## Project Overview
This project is a dynamic business reporting dashboard built in Microsoft Excel using 7,500+ rows of B2B travel booking data.

The dashboard helps analyze:
- Revenue trends
- Destination performance
- Traveler segmentation
- Activity distribution
- Channel performance
- Monthly booking trends

The project was created to simulate a real-world business intelligence and reporting workflow.

---

## Dashboard Features

### KPI Cards
- Total Revenue
- Total Bookings
- Average Spend
- Highest Revenue Market
- Most Popular Activity

### Interactive Dashboard
- Dynamic slicers and timeline filters
- Revenue trend analysis
- Activity distribution analysis
- Traveler segmentation
- Revenue by channel analysis

### Pivot Analysis
- Revenue by destination
- Monthly revenue trends
- Traveler type performance
- Activity popularity analysis

## Business Insights Generated
- Q4 showed stronger booking performance.
- Adventure activities generated higher engagement.
- Corporate travelers contributed maximum revenue.
- Hongkong and Thailand emerged as top-performing destinations.
